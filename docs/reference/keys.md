# Keys

<kbd>?</kbd> shows a summary inside the app.

## Everywhere

| Key | Action |
|---|---|
| <kbd>j</kbd>/<kbd>k</kbd>, <kbd>↑</kbd>/<kbd>↓</kbd> | Move |
| <kbd>g</kbd>/<kbd>G</kbd> | Top / bottom |
| <kbd>ctrl+d</kbd>/<kbd>ctrl+u</kbd> | Half a page down / up |
| <kbd>enter</kbd> <kbd>l</kbd> <kbd>→</kbd> | Open |
| <kbd>h</kbd> <kbd>←</kbd> <kbd>esc</kbd> | Back |
| <kbd>m</kbd> | Macros |
| <kbd>p</kbd> | Cycle the watch poll interval: 5, 10, 20, 30, 60s (saved) |
| <kbd>a</kbd> | Toggle the cat's animation |
| <kbd>?</kbd> | Help |
| <kbd>q</kbd> | Back; quit from the jobs screen |
| <kbd>ctrl+c</kbd> | Quit |

## Jobs list

| Key | Action |
|---|---|
| <kbd>/</kbd> | [Search](/guide/search) this folder, then every other one |
| <kbd>b</kbd> | Build (asks first; opens the form for parameters) |
| <kbd>L</kbd> | Open the last build's log |
| <kbd>x</kbd> | Abort the last build if it's running (asks first) |
| <kbd>w</kbd> | Watch or stop watching |
| <kbd>J</kbd>/<kbd>K</kbd> | Move a watched job down / up |
| <kbd>o</kbd> | Open in the browser |
| <kbd>r</kbd> | Refresh the folder, the search index and the watched jobs |

## Builds

| Key | Action |
|---|---|
| <kbd>enter</kbd> | Open the build's log |
| <kbd>b</kbd> | Build |
| <kbd>x</kbd> | Abort the selected build (asks first) |
| <kbd>i</kbd> | Answer a pending input |
| <kbd>w</kbd> | Watch or stop watching |
| <kbd>o</kbd> | Open the build in the browser |
| <kbd>r</kbd> | Refresh |

## Log

| Key | Action |
|---|---|
| <kbd>f</kbd> | Toggle following new output |
| <kbd>g</kbd>/<kbd>G</kbd> | Top / bottom (bottom also resumes following) |
| <kbd>i</kbd> | Answer a pending input |
| <kbd>x</kbd> | Abort the build (asks first) |
| <kbd>o</kbd> | Open the console in the browser |

## Forms

| Key | Action |
|---|---|
| <kbd>tab</kbd> / <kbd>shift+tab</kbd> | Next / previous field |
| <kbd>←</kbd>/<kbd>→</kbd>, <kbd>space</kbd> | Change a choice or a checkbox |
| <kbd>enter</kbd> | Build, proceed, or save the macro step |
| <kbd>ctrl+x</kbd> | Abort the input step |
| <kbd>esc</kbd> | Cancel |

## Macros

| Key | Action |
|---|---|
| <kbd>enter</kbd> | Run (asks first) |
| <kbd>n</kbd> | New macro |
| <kbd>e</kbd> | Edit |
| <kbd>d</kbd> | Delete (asks first) |
| <kbd>c</kbd> | Cancel the running macro |

The editor's keys are listed in [Macros](/guide/macros#creating-one).
